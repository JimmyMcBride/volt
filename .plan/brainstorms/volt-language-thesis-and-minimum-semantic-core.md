# Brainstorm: Volt language thesis and minimum semantic core

Started: 2026-07-26T05:38:11Z

## Focus Question

Which workloads should Volt serve, and which smallest set of semantics would make AI-agent-written programs safer, more deterministic, and easier for humans to govern?
## Desired Outcome

An approved, bounded language thesis and minimum semantic-core spec that can
drive one executable vertical slice.

## Vision

Volt is a brand-new programming language focused on AI agents as first-class
program authors and operators. It should help agents produce software that is
more deterministic, verifiable, and repairable while keeping humans in control.

## Refinement

### Problem

AI agents program through languages and tools designed mainly for human authors. Critical behavior, effects, diagnostics, and repair loops often remain implicit, making generated software harder to verify and govern.

### User / Value

AI coding agents gain a deterministic, machine-legible environment for creating and repairing programs. Human developers gain software that is easier to inspect, constrain, review, and trust.
